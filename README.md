## ✨ 关于项目 (About)

**鼠标样式实验室** 是一个纯前端打造的交互式网页应用。在这里，你可以直观地预览和体验各种系统默认的鼠标光标，以及我亲手绘制的自定义 SVG 特效光标。

项目采用了现代的**深色毛玻璃 (Glassmorphism)** UI 设计，不仅是一个实用的 CSS 参考工具，更是一个充满趣味的小玩具。≽^⚈⩊⚈^≼

## 🌟 功能亮点 (Features)

- 🎨 **20+ 基础系统光标**：涵盖 `default`, `pointer`, `text`, `resize` 等所有标准 CSS 光标状态。
- ✨ **12+ 自定义特效光标**：包含魔法轨迹、火焰拖尾、猫咪爪印、霓虹光圈等纯 CSS/SVG 实现的趣味光标。
- 🌙 **现代深色 UI**：采用毛玻璃特效、平滑过渡动画和渐变背景，视觉体验极佳。
- 📱 **完全响应式**：完美适配桌面端和移动端浏览。
- 🚀 **零依赖**：纯原生 HTML / CSS / JavaScript 编写，无需任何框架，轻量极速。

## 🛠️ 技术栈 (Tech Stack)

| 技术 | 说明 |
| :---: | :--- |
| **HTML5** | 语义化页面结构 |
| **CSS3** | Flexbox/Grid 布局、毛玻璃特效、Keyframe 动画、SVG 光标定义 |
| **JavaScript** | 原生 DOM 操作，实现无刷新交互预览 |
